Modélisation du risque d’assurance par simulation Monte-Carlo

Projet personnel réalisé en Python dans le cadre de mon apprentissage en mathématiques financières.

L’objectif est de simuler les pertes annuelles d’un portefeuille fictif d’assurance à partir de modèles probabilistes, puis d’analyser la variabilité des pertes à l’aide de simulations Monte-Carlo.

Méthodes utilisées : lois de Poisson et exponentielle, simulation Monte-Carlo, analyse de distributions et visualisation des données.

Outils : Python, NumPy, Matplotlib et Jupyter Notebook.

Le dépôt contient le notebook Python ainsi qu’un rapport PDF présentant la méthodologie, l’analyse et les limites du modèle.

Projet pédagogique basé sur des hypothèses et des paramètres fictifs.
